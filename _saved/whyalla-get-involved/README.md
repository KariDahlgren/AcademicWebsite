# Saved: Whyalla Futures "Get involved" page

Taken off the Whyalla Futures Research site until ethics approval for participant
recruitment is in place. Folders starting with `_` are not published by GitHub Pages,
so this page is kept here but is not live.

A viewable copy is saved as a private artifact, "Whyalla Get Involved":
https://claude.ai/artifact/8aD4PMQ99YSf6NRHPKQv9D

## To put it back
1. Move `index.html` back to `whyalla/get-involved/index.html`.
2. Fill in the MUHREC project ID, complaints contact and the two PDFs
   (PDFs go in `whyalla/documents/`).
3. If using Qualtrics, paste the survey link into `QUALTRICS_URL` in `whyalla/whyalla.js`.
4. Re-add the links on `whyalla/index.html`: "Get involved" in the header nav and a
   header button, the hero "Get involved" button, and "Get in touch" under
   "What the project will make".
5. The Ethics page is also saved, in `_saved/whyalla-ethics/`. Restore it first, then point its
   header back link to `/whyalla/get-involved/`.
6. Add `https://karidahlgren.org/whyalla/get-involved/` back to `sitemap.xml`.
